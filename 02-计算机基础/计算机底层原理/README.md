# 计算机底层原理

> 本目录收「**后端开发用得上的那部分执行与存储**」：一条机器码指令在 CPU 里走哪五段、为什么 IPC 能大于 1、分支预测失败到底浪费了什么、乱序与写缓冲如何引出内存屏障；以及一次访存落在哪一层、缓存行为什么是 64 字节、MESI 四态如何解释「写一个字节要抢整行」、伪共享的判据与测法。
>
> 当前 **3 篇**：[CPU怎么执行一条指令.md](CPU怎么执行一条指令.md)——从「同样的 2 亿次加法，三种依赖结构耗时差 4.85 倍」这个读数出发，把五段流水线、超标量、预测失败、写缓冲串成一条线，末尾收口到 `LOCK` 前缀为什么必须存在；[CPU缓存与缓存行.md](CPU缓存与缓存行.md)——从「两个 goroutine 各加各的却慢 4 倍」出发，用间隔夹逼出 64 字节，讲 MESI 与伪共享判据、四类假阴性与排查四步；[原子操作与互斥的实现.md](原子操作与互斥的实现.md)——从「三个线程各加一百万次少了四成」出发，用汇编、跨行实验与 `strace` 把「硅 → 内核 → 语言壳」三层拆开：`LOCK` 锁的是缓存行（跨行贵 175 倍）、无竞争互斥不进内核（200 万次加锁只有 124~556 次系统调用）、x86 上大半屏障是白送的。
> ⚠️ 其余规划篇目**仍未写出**，见下面「二、规划篇目」的缺口登记。
>

## 一、本目录收什么？与相邻目录的边界在哪？

**本节要点**：判据是「**这条结论落在硅里，还是落在内核里，还是落在翻译过程里**」。三者都成立「换语言也成立」，但回答的是不同问题。

| 归本目录 | 不归本目录，归 | 原因 |
|---|---|---|
| 取指 / 译码 / 执行 / 访存 / 退休、流水线、超标量、IPC | [编译原理/](../编译原理/)（源码 → 产物那一段） | 一边是「机器码怎么被造出来」，一边是「机器码怎么被执行」 |
| 分支预测、乱序执行、写缓冲、重排缓冲 | [操作系统/](../操作系统/)（进程与调度） | OS 管「**谁**用 CPU」，本目录管「CPU 怎么执行**一条**指令」 |
| 缓存层次（L1/L2/L3）、缓存行、伪共享 | [操作系统/](../操作系统/)（页表与缺页） | 一个是**物理缓存**，一个是**地址翻译**；两者常被混为一谈 |
| 内存屏障的**物理原因** | [Go内存模型.md](../../01-编程语言/go/并发编程/Go内存模型.md)、[JMM与内存屏障.md](../../01-编程语言/java/并发编程/JMM与内存屏障.md)（语言层的内存序） | 语言规定「**什么能重排**」，本目录解释「**为什么会重排**」 |
| 指令集架构（x86 变长 / arm64 定长）对编码的影响 | [编译原理/机器码、字节码与opcode.md](../编译原理/机器码、字节码与opcode.md)（编码格式本身） | 一边是「字节怎么拼」，一边是「拼出来的字节怎么被译码器切」 |

⭐ 最容易搞混的是第二行：`操作系统/README.md` 的缺口登记里有一条「中断、调度与 CPU 时间片」，那是**调度**视角（分给谁、分多久）；本目录的「五段流水线」是**执行**视角（拿到之后怎么算）。两者正交，不重复。

## 三、这些内容现在在哪？

**本节要点**：先建立边界，**不搬动已有结论**；写新篇时再从这些位置回收共性判断。

- **`LOCK` 前缀的汇编证据** → [Go内存模型.md](../../01-编程语言/go/并发编程/Go内存模型.md) 4.1 节（`LOCK XADDQ` 与普通 `INCQ` 的对照）。本目录只补「为什么要清写缓冲」，不重放那份汇编。
- **第一条指令是怎么来的** → [从可执行文件到第一条指令.md](../编译原理/从可执行文件到第一条指令.md) 第四节（C 的 `_start` 12 条 / Go 的 `_rt0_amd64` 3 条）。本目录从「PC 拿到地址之后」接起。
- **字节怎么编码** → [机器码、字节码与opcode.md](../编译原理/机器码、字节码与opcode.md) 第三节（REX / ModRM / SIB / rel32）。本目录 2.2 的「切边界」是它的译码侧。
- **缺页与页表** → [用户态内核态与一次IO的内存路径.md](../操作系统/用户态内核态与一次IO的内存路径.md)。那是地址翻译，比本目录的 L1d 命中晚一个量级。
- **指令集不可移植的现场表现** → [从可执行文件到第一条指令.md](../编译原理/从可执行文件到第一条指令.md) 7.3（`exec format error` 与退出码 126）。
