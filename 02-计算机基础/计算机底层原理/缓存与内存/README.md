# 缓存与内存

> 本册收**一次访存落在哪一层、为什么以「行」为单位被搬来搬去，以及两个核共享同一行时顺序靠什么保证**：存储层次的延迟台阶、64 字节的夹逼、MESI 四态、伪共享的判据与测法、四种重排只漏一种、各类屏障的单价。判据是「**换语言也成立，但它不是 CPU 的执行逻辑**」——数据在哪、几个核怎么共享，属存储层次。

## 一、本册收什么

**本节要点**：一句话——「**数据从 L1 到内存要几纳秒，两个核想要同一份数据时会怎样，以及为此要付多少钱**」。执行逻辑在 [微架构/](../微架构/)，地址翻译在 [操作系统/](../../操作系统/)。

前半句是「数据在哪」（延迟台阶 + 行宽 + MESI），后半句是「顺序与代价」（四种重排 + 屏障单价）。两篇合起来回答一个完整的问题：一次跨核共享，从「数据搬过来」到「顺序对得上」，各花多少。

## 二、分工表

**本节要点**：两篇的分工线是「**结构 vs 代价**」——第一篇讲缓存行是什么、怎么被抢；第二篇讲抢完之后要等多久、等的那条指令多少钱。

| 篇 | 回答什么 | 状态 |
|---|---|---|
| [CPU缓存与缓存行.md](CPU缓存与缓存行.md) | 各级延迟差多少；缓存行为什么是 64 字节且能用间隔夹逼出来；MESI 四态怎么解释「写一个字节要抢整行」；伪共享怎么判、怎么测、哪四类假阴性 | ✅ 已落地（1.60 → 113.63 ns；间隔 56 慢 / 64 快；行宽 ∈ (56,64]） |
| [内存屏障与内存序的代价.md](内存屏障与内存序的代价.md) | 四种重排 x86 只漏哪一种；不拦会被观测成什么样；`mfence` / `lfence` / `sfence` / `lock or` / `cpuid` 各多少钱；编译器屏障与硬件屏障差在哪 | ✅ 已落地（无屏障 300 000 轮违反 29~41 次，加屏障三轮全 0；单价 0.46 → 2.46 → 5.37 → 7.5~8.1 → 15.21 → 725.57 ns） |

⚠️ 两篇靠一条线分开：**第一篇不讨论顺序，第二篇不讨论一致性协议**。屏障篇第 1.3 节只用一句「写还在缓冲里，缓存里还是旧值」把 MESI 接过来，不重述四态；缓存篇第 221 行把 `LOCK` 语义外链到 [原子操作.md](../底层同步/原子操作.md)，不重述前缀。

## 三、读序

**本节要点**：先结构后代价——不先建立「行」的概念，屏障篇的「还账」就没有对象。

1. 先读 [CPU缓存与缓存行.md](CPU缓存与缓存行.md)：延迟台阶（16 KB 1.60 ns → 64 MB 113.63 ns）→ 64 字节怎么夹出来 → MESI 四态 → 伪共享四类假阴性；
2. 再读 [内存屏障与内存序的代价.md](内存屏障与内存序的代价.md)：从那个 0.01% 的观测开始，回到「四种重排只漏一种」，最后落到单价表。
3. 两篇之后接 [底层同步/](../底层同步/)：那里把「抢一条行」拆成 `lock` 前缀锁什么（原子操作），再往下变成「线程睡下」（互斥的实现）。

## 五、实测坐标

**本节要点**：两篇的读数都在同一台机器的容器内测得，绝对值受虚拟化影响；**结论本身不受影响**（夹逼出的是区间判定，屏障比的是同进程倍数）。

| 项 | 值 |
|---|---|
| 宿主 CPU | Intel Core i7-6700HQ（L1d 32 KB/核、L2 256 KB/核、L3 6 MB 共享） |
| 容器 | `golang:1.26-bookworm`（Go 1.26.5 侧）/ `gcc 12.2.0`（C 侧对拍） |
| 内核 | 6.18.54.1-microsoft-standard-WSL2，cgroup 限额 4 CPU |
| 关键方法 | 工作集逆序扫（延迟台阶）；**起点强制 64 对齐**后手工控间隔（夹逼）；`@Contended` 需 `-XX:-RestrictContended`；SB litmus 用手写汇编 + `pthread_barrier` 夹轮次 |

⚠️ 三个已知坑：`new(T)` 的起点 mod 64 是随机的（0/16/32/48 各 1/4），不对齐会让「间隔 32」碰巧跨行；`internal/cpu.CacheLinePad` 外部不可引，`x/sys` 版的偏移与 size 都不同；`xchg` 的内联汇编**不能拿循环计数器当交换对象**，否则循环提前退出、读数是 0.000 ns。

⚠️ 跨核 store 可见延迟（两核互等写入的 ping-pong）试过但放弃：三轮测出 15 / 26 / 84 ns 每跳，同一配置波动 6 倍，WSL2 的调度噪声盖过了要测的量。屏障篇因此改用 SB litmus 做主力证据。
