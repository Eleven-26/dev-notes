# 线性结构

> 本目录（`02-计算机基础/数据结构/线性结构/`）收**四种逻辑结构里最基础的一族** —— 元素之间**一对一**：
> 一个前驱、一个后继，于是它只剩两个自由度：**怎么放**（连续还是离散）与**在哪进出**。
> 存储基座是 [数组与链表.md](数组与链表.md)；在它之上限制存取位置，得到 [栈与队列.md](栈与队列.md)；
> 再把两端都放开、并让数组首尾相接，就是 [双端队列与循环队列.md](双端队列与循环队列.md)。
>
> 本篇是**入口导读** —— 只给清单、阅读顺序与这一族内部的判别。
> **跨族的选型总表（操作复杂度 / 隐藏代价 / 典型场景）在 [README.md](../README.md) 第三节**；
> 线性结构在四种逻辑结构里的位置见 [README.md](../README.md) 第二节；结构与算法的分工见 [算法/README.md](../../算法/README.md)。

## 一、本目录收录哪三篇？

**本节要点**：三篇是**基座 → 受限表 → 结构变体**的递进关系，后一篇都建立在前一篇的存储形态上。

| 文件 | 一句话职责 | 类型 |
|---|---|---|
| [数组与链表.md](数组与链表.md) | **两种物理存储的基座**：数组真正的红利是「可预取」而不是「`O(1)`」；链表「`O(1)` 插入」背后的三笔钱（定位 / 指针 / 分配） | 存储基座 |
| [栈与队列.md](栈与队列.md) | **运算受限的线性表**：LIFO 与 FIFO 各自换来什么、链栈为什么不需要头结点、队列「上磁盘」之后设计目标为什么会变 | 受限表 |
| [双端队列与循环队列.md](双端队列与循环队列.md) | **队列的两个结构变体**：环形数组把出队搬移换成取模（实测搬移 `49995000 → 0`）、判空判满三种写法的容量代价、Deque「两端都 `O(1)`」的来处 | 结构变体 |

## 三、这一族内部怎么选？

**本节要点**：先问**在哪儿增删**（一端 / 两端 / 任意位置），再问**要不要按下标访问** —— 两个问题答完，结构就定了。

| 要做什么 | 用哪个 | 判据 |
|---|---|---|
| 按下标随机访问、以顺序扫描为主 | 数组（Go 切片 / Java `ArrayList`） | 地址连续 ⇒ 缓存行整块命中、预取器生效 —— 这才是它比链表快的真正原因 |
| 频繁增删、长度不可预估 | 链表（工程上多为池化分配，或用数组下标模拟） | ⚠️ 「插入 `O(1)`」的前提是**已经定位到那个节点**；定位本身仍是 `O(n)` |
| 只在**一端**进出 | 栈 | LIFO 保证「最近的最先被处理」：撤销、表达式求值、递归 |
| 只在两端、先来先服务 | 队列（上了磁盘就是消息队列） | FIFO 保证「先到的先处理」：任务排队、BFS 的 frontier |
| **两头**都要 `O(1)` 进出 | 双端队列（环形数组实现） | 两端各持一个下标，插入删除只动下标、不搬元素 |
| 定长缓冲、生产与消费循环复用 | 循环队列 | 把出队搬移换成 `(head+1) % n`；⚠️ **留一个空位**才区分得开「空」与「满」 |

⚠️ **两个高频混淆**：① **栈和队列不是新的存储结构** —— 它们只是给线性表加了一条「从哪进出」的约束，底层仍是数组或链表；
② **滑动窗口最值不属于本目录** —— 那是「用结构解题」的单调队列，见 [单调栈与单调队列.md](../高级数据结构/单调栈与单调队列.md)。

## 延伸追问

- **数组和链表的本质区别是什么？** → 内存连续性。数组靠偏移量 `O(1)` 定位但增删要搬移；链表靠指针 `O(n)` 遍历但增删只改指针。
- **既然都是 `O(1)`，为什么说数组的 `O(1)` 更值钱？** → 数组地址连续，CPU 预取器与缓存行能整块命中；链表的下一节点地址要先解引用才知道，几乎每个节点一次缓存 miss。
- **队列「上磁盘」之后为什么设计目标变了？** → 内存队列优化的是「进出 `O(1)`」，磁盘队列优化的是「顺序追加 + 顺序读 + 持久化」，于是变成日志结构（见 [Kafka.md](../../../03-数据与中间件/中间件/消息队列/Kafka.md)）。
- **环形数组的容量为什么常取 2 的幂？** → 把取模换成 `& (n-1)`，省掉一次除法；代价是容量不能任意指定。
- **栈和队列在算法里怎么被用到？** → BFS 用队列逐层扩散（[BFS广度优先遍历.md](../../算法/图论算法/图的遍历/BFS广度优先遍历.md)），树的迭代遍历用栈模拟递归（[树的遍历.md](../树/树的遍历.md)）。
