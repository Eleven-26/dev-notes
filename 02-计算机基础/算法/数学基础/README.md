# 数学基础

> 本目录（`算法/数学基础/`）收**编程题里反复出现的数学工具**四篇：
> [数论基础.md](数论基础.md)（整数结构：GCD / 筛法 / 快速幂 / 逆元）、
> [组合数学.md](组合数学.md)（计数：排列组合 / 容斥 / Catalan / 卢卡斯）、
> [概率与期望.md](概率与期望.md)（随机性：条件概率 / 期望线性性 / 期望 DP）、
> [博弈论.md](博弈论.md)（决策：Nim / SG 函数 / 公平组合游戏）。
>
> 本篇是**入口总纲** —— 回答「这四样各自回答什么问题、什么时候在代码里出现、彼此谁依赖谁」。
> ⚠️ **具体公式的推导与实现在各自的零件篇里**，本篇只给判据与阅读顺序；
> 算法目录整体导读见 [README.md](../README.md)，复杂度口径见 [复杂度分析.md](../基础算法/复杂度分析.md)。

## 一、核心思想

**本节要点**：这四篇的共同底色是「**把代码问题化成数学问题**」—— 枚举不动的时候，靠结构（数论）、靠计数（组合）、靠线性性（期望）、靠不变量（博弈）把指数级压成闭式解。

| 篇 | 回答的问题 | 代码里什么时候出现 |
|---|---|---|
| [数论基础.md](数论基础.md) | 整数的**结构**：公约数、素性、模运算怎么走 | 哈希取模、大指数取模、组合数除法（逆元）、RSA/校验类场景 |
| [组合数学.md](组合数学.md) | 「**数方案**」：满足条件的对象有多少个 | 「至少 / 至多 / 恰好」计数、卡特兰数形态（合法括号、出栈序列）、对大质数取模 |
| [概率与期望.md](概率与期望.md) | 「**平均意义**」：随机过程的期望值 | 随机算法的期望复杂度、期望 DP（掷骰子/抽卡类题）、贝叶斯判定 |
| [博弈论.md](博弈论.md) | 两人最优决策下「**谁必胜**」 | 取石子类游戏、轮流操作判输赢、异或不变量 |

⭐ 一句话区分：**数论管「整数的形状」，组合管「数方案」，概率管「平均」，博弈管「对手」**。

动态规划/记忆化搜索.md ◄──免填表顺序── 博弈论.md（SG 函数天然记忆化）

## 三、什么时候进本目录（选型判据）

**本节要点**：先问「题目里的对象是**数**、**方案**、**随机变量**还是**对手**」，四选一直接落到篇目。

```text
□ 出现「模质数 P」的大数运算（a^b mod P、组合数 mod P）
│   └─ 数论基础.md（快速幂、逆元）＋ 组合数学.md（卢卡斯定理）
□ 问「有多少种方案 / 至少一个 / 恰好 k 个」
│   └─ 组合数学.md（容斥是「至少」的标准工具）
□ 问「平均要多少次 / 期望得分 / 随机过程的稳态」
│   └─ 概率与期望.md（先试期望线性性，拆指示变量；不行再上期望 DP）
□ 两人轮流操作、无法操作者输、问先手必胜
│   └─ 博弈论.md（Nim 异或 → SG 函数）
□ 值域大但只「取模 / 判素 / 求 gcd」以外的结构？
    └─ 不属于本目录：区间维护看 [高级技巧/](../高级技巧/README.md)，
       字符串计数看 [字符串匹配/](../字符串匹配/README.md)
```

⚠️ **数论分块（整除分块）不在本批篇目里**：[数论基础.md](数论基础.md) 只覆盖 GCD / 筛法 / 快速幂 / 逆元 / 扩展欧几里得，没讲「按商分组」那套；用到它的题目前要另行补篇（与 [分块.md](../高级技巧/分块.md) 只同「分块」二字，思想不同源）。

## 五、常见陷阱

**本节要点**：四篇的坑全在「**模与除、独立性与线性性、公式记忆**」三处 —— 都是结果直接错、却不报错的那类。

| 陷阱 | 症状 | 怎么避免 |
|---|---|---|
| 模意义下直接用 `/` | 组合数取模结果错得离谱 | 除法一律换成**乘逆元**（[数论基础.md](数论基础.md) 第五节） |
| 筛法当判素用（n 很大单点问） | 开不出那么大的数组 | 单点判素用试除 / Miller-Rabin 思路（[数论基础.md](数论基础.md)） |
| 「期望线性性」当成「要独立」 | 明明能用指示变量却去算联合分布 | 线性性**不要求独立**，这是它最值钱的地方（[概率与期望.md](概率与期望.md)） |
| 博弈题硬找必胜策略 | 状态一大就没思路 | 判胜只需 SG/Nim 值，**不需要构造策略**（[博弈论.md](博弈论.md)） |
| Catalan / 斯特林公式记错首项 | 差一个下标全盘皆错 | 用零件篇里的**小数字手推表**对账，别背裸公式（[组合数学.md](组合数学.md)） |
| 快幂 / 阶乘表 int 溢出 | 取模前就已溢出 | 每步乘法立即取模；用 `int64`（[数论基础.md](数论基础.md) 第四节） |
