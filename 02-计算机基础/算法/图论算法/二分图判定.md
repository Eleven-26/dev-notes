# 二分图判定

> 能否把图的顶点分成两组，使所有边都跨组 —— 这就是二分图判定，
> 本质是「两色染色」，用 BFS / DFS 即可 O(V+E) 解决。
>
> ⭐ 边界先说清：本篇讲二分图的判定与基础性质。
> 最大匹配（匈牙利算法）写在 [二分图匹配.md](二分图匹配.md)，本篇不展开。
>
> 内容整理自个人学习笔记，素材见 [素材清单](../../../素材清单.md)。复杂度口径见 [复杂度分析.md](../基础算法/复杂度分析.md)。

## 一、什么是二分图？为什么等价于「不含奇环」？

**本节要点**：定义只有一句话（边全部跨组），但真正好用的是它的等价判据 —— **有没有奇数长度的环**。

- **二分图**：顶点可分成两个互不相交的集合 U、V，每条边的两个端点分别属于 U 和 V
- 等价说法：**不含奇环**（奇数长度的环）
- 判定方法：两色染色，相邻节点颜色不同

⭐ 两句话把「等价」说圆：能两色染色 ⇒ 沿任何环走一圈颜色必须正负交替 ⇒ 回到起点要求环长为偶数；反过来无奇环时从任意点染色永远不会撞色。完整推导在「延伸追问」第一条。

## 二、两色染色怎么判？

**本节要点**：BFS / DFS 逐个连通分量染色，遇到「邻居已染色且同色」即判负；⚠️ 图可能不连通，每个未染色点都要重新起一次。

```go
func isBipartite(g [][]int) bool {
	color := make([]int, len(g)) // 0=未染色, 1/-1=两种颜色
	for i := range g {
		if color[i] != 0 {
			continue
		}
		color[i] = 1
		queue := []int{i}
		for len(queue) > 0 {
			u := queue[0]
			queue = queue[1:]
			for _, v := range g[u] {
				if color[v] == 0 {
					color[v] = -color[u]
					queue = append(queue, v)
				} else if color[v] == color[u] {
					return false // 冲突，非二分图
				}
			}
		}
	}
	return true
}
```

- 遍历每个未染色节点，BFS / DFS 染色
- 遇到同色相邻 → 非二分图
- ⚠️ **图可能不连通**，要对每个连通分量分别判

⭐ 与 [BFS广度优先遍历.md](图的遍历/BFS广度优先遍历.md) 的分工：「队列一圈圈扩」的模板写在它第一节，本篇不重复；**区别只在往队列里放东西的判据** —— 无权最短路记录的是「到起点的距离」，永不拒绝；染色记录的是「正 / 负两值」，同色相邻立刻判负退出。DFS 版染色的递归骨架见 [DFS深度优先遍历.md](图的遍历/DFS深度优先遍历.md)。

拿一张含奇环的 4 点图把染色推进逐步过一遍（边表：0—1, 0—2, 1—2, 1—3, 2—3；`+` 染 1，`−` 染 −1，数字可手推复核）：

```text
步骤  出队 u  动作                                    颜色[0,1,2,3]   队列
 1     —      0 是首个未染点，染 + 入队                 [+,0,0,0]      [0]
 2     0      邻居 1、2 未染 → 各染 −                  [+,−,−,0]      [1,2]
 3     1      邻居 3 未染 → 染 +                       [+,−,−,+]      [2,3]
 4     1      邻居 2 已染 −，与 1 同色 → 冲突，返回 false

冲突点正是奇环 0—1—2—0。把边 1—2 删掉再跑：不再冲突，
染色结果 [+,−,−,+] ⇒ 两组 {0,3} 与 {1,2}，是二分图（四边形 0—1—3—2—0）。
```

## 三、这套判定要花多少代价？

**本节要点**：每个点、每条边各碰一次，线性。

| 维度 | 值 |
|---|---|
| 时间 | O(V + E) |
| 空间 | O(V) |

## 四、判定之后能干什么？

**本节要点**：「能分成两组」这个性质本身就是一大类建模的前提 —— 冲突图先验一下是不是二分图。

| 场景 | 说明 |
|---|---|
| 关系划分 | 把「互相冲突」的对象分成两组 |
| 任务分配 | 二分图最大匹配的前置判定，见 [二分图匹配.md](二分图匹配.md) |
| 二着色问题 | 如地图着色、频道分配 |
| 奇环检测 | 判断图中是否有奇数长度的环 |
| 2-SAT 简化 | 某些 2-SAT 可转化为二分图，见 [2-SAT.md](2-SAT.md) |

## 五、动态加边时为什么改用「种类并查集」？

**本节要点**：BFS 染色是「一次性快照」，边一条条进来时它要整体重跑；种类并查集能把染色约束做成增量维护。

- 二分图判定可以用**种类并查集**（带权并查集 / 扩展域并查集）解决
- 把每个点拆成两份（与自身对立的另一色），合并时检查矛盾
- ⚠️ 并查集判定适合**动态加边**场景；BFS 染色适合一次性判定

⭐ **判据**：边会持续加入 → 种类并查集；图是静态的、判一次就完 → BFS 染色。并查集的机制（路径压缩、按秩合并）写在 [并查集、Trie与一致性哈希.md](../../数据结构/高级数据结构/并查集、Trie与一致性哈希.md)，本篇不复述。

## 延伸追问

- **二分图为什么等价于无奇环？** → 若能两色染色，沿环走一圈颜色交替；回到起点要颜色相同，说明环长为偶数。
- **图不连通时怎么判？** → 对每个未染色节点重新启动 BFS / DFS。
- **二分图的最大匹配怎么求？** → 匈牙利算法 O(VE) 或 Hopcroft-Karp O(E√V)，见 [二分图匹配.md](二分图匹配.md)。
- **种类并查集和 BFS 染色怎么选？** → 边动态加入 → 种类并查集；一次性判定 → BFS 染色。
- **二分图有哪些应用？** → 任务分配、婚配问题、最小点覆盖、最大独立集。
