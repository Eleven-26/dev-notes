# 欧拉路径与欧拉回路

> 一笔画问题：能否不重复地经过每条边恰好一次 —— Hierholzer 算法
> O(V+E) 求出路径。
>
> ⭐ 边界先说清：本篇讲欧拉路径与欧拉回路。
> 哈密顿路径（不重复经过点）是 NP 困难的，与本篇不同。
> DFS 基础见 [DFS深度优先遍历.md](图的遍历/DFS深度优先遍历.md)。
>

## 一、欧拉路径、欧拉回路、半欧拉图分别指什么？

**本节要点**：四个词只差两件事 —— 要不要回到起点、存不存在。

| 概念 | 定义 |
|---|---|
| **欧拉路径** | 经过每条边恰好一次的路径 |
| **欧拉回路** | 起点 = 终点的欧拉路径 |
| **欧拉图** | 存在欧拉回路的图 |
| **半欧拉图** | 存在欧拉路径但不存在欧拉回路的图 |

## 二、判一笔画通不通，只看度数够吗？

**本节要点**：度数条件只管「进出配不配平」，还差一条「边得连成一气」—— 连通性（对含边的分量而言）不能省。

### 2.1 无向图

| 类型 | 条件 |
|---|---|
| 欧拉回路 | 所有顶点度数为偶数，且图连通 |
| 欧拉路径 | 恰好 0 或 2 个顶点度数为奇数，且图连通 |

### 2.2 有向图

| 类型 | 条件 |
|---|---|
| 欧拉回路 | 所有顶点入度 = 出度，且图连通 |
| 欧拉路径 | 恰好一个点出度 − 入度 = 1（起点），一个点入度 − 出度 = 1（终点），其余入度 = 出度 |

⭐ 直觉：路径每「借道」一个点就要一进一出配平一次；只有起点（多一次出发）和终点（多一次到达）允许配不平 —— 回路则连这俩都省了。

## 三、Hierholzer 为什么「回溯时记录、最后反转」？

**本节要点**：DFS 走到无路可走才记点，记录的顺序天然是「从终点倒着往回退」，反转即正解；走歪了的子环会被完整地嵌回主环里。

```go
func eulerPath(g [][]int, start int) []int {
	var path []int
	var dfs func(u int)
	dfs = func(u int) {
		for len(g[u]) > 0 {
			v := g[u][0]
			g[u] = g[u][1:]
			dfs(v)
		}
		path = append(path, u)
	}
	dfs(start)
	// path 是逆序
	for i, j := 0, len(path)-1; i < j; i, j = i+1, j-1 {
		path[i], path[j] = path[j], path[i]
	}
	return path
}
```

⭐ **核心**：DFS 到底后回溯时加入路径，最后反转。

- 时间 O(V + E)
- 空间 O(V + E)

在「两个环共享一个点」的 6 边图上推一遍（从 0 出发，邻接表按出现顺序取边，数字可手推复核）：

```text
有向边表：0→1, 1→2, 2→0, 0→3, 3→4, 4→0（每点入度 = 出度，存在欧拉回路）
邻接表： g[0]=[1,3]  g[1]=[2]  g[2]=[0]  g[3]=[4]  g[4]=[0]

深入阶段： 0 →1 2 →0 →3 4 →0（g[0] 已空，开始回溯）
回溯记录序： 0, 4, 3, 0, 2, 1, 0     ← 每离开一个点记一次
反转后     ： 0, 1, 2, 0, 3, 4, 0     ✓ 六条边各踩一次、回到起点

对照「歪路兜底」：中途 2→0 其实提前撞回了起点，但 g[0] 还剩 3 这条出边，
DFS 就地续走第二个环 —— 这正是「回溯时记录」保证子环不漏的原因。
```

## 四、什么问题是一笔画的马甲？

**本节要点**：凡是「每条通道必须走且只走一遍」的覆盖类问题。

| 场景 | 说明 |
|---|---|
| 一笔画 | 图形是否能一笔画完 |
| 邮递员问题 | 走遍所有街道的最短路径 |
| 电路板测试 | 走遍所有线路 |
| 单词接龙 | 每个单词用一次 |
| DNA 序列拼接 | 短序列拼接成长序列 |
| 扫雪车路线 | 扫遍所有街道 |

## 五、最容易踩的坑有哪些？

**本节要点**：判定看度数、实现看删边 —— 两头都有活要干。

| 坑 | 说明 |
|---|---|
| **图不连通** | 要检查所有边是否在同一连通分量 |
| **孤立点** | 度数为 0 的点不影响判定 |
| **重边** | Hierholzer 用边的编号而不是顶点编号来避免重边问题 |
| **有向图的起点** | 有向图要先找出度 − 入度 = 1 的点作为起点 |
| **逆序输出** | Hierholzer 输出的是逆序，要反转 |

## 延伸追问

- **欧拉路径和哈密顿路径的区别？** → 前者经过每条**边**一次，后者经过每个**点**一次；前者 O(V+E)，后者 NP 困难。
- **Hierholzer 为什么要反转？** → DFS 回溯时加入的是逆序，反转后才是正的路径。
- **多重图怎么处理？** → 用边的编号标记已访问，或直接从邻接表删除。
- **欧拉回路的起点怎么选？** → 任意一个度数非 0 的点都可作为起点。
- **欧拉路径的终点怎么确定？** → 无向图中度数为奇数的两个点分别是起点和终点。
