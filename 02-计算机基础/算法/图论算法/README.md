## 一、核心思想

**本节要点**：图论问题**只有几个母题** —— 遍历、最短路、最小生成树、拓扑排序、连通性、一笔画、二分图、网络流、逻辑约束、数值约束、树上问题。把一个问题归类到母题，比背算法名字有用得多。

| 母题 | 在问什么 | 代表算法 |
|---|---|---|
| **遍历** | 怎么不重不漏地走遍所有点 / 边 | DFS、BFS |
| **最短路** | 两点（或所有点对）之间的最小代价 | Dijkstra、Bellman-Ford、Floyd |
| **最小生成树** | 用最小的总代价把所有点连通起来 | Kruskal、Prim |
| **拓扑排序** | 把有向无环图「拉成一条线」 | Kahn（BFS）、DFS 后序 |
| **连通性** | 哪些点互相可达 / 谁是割点 / 一笔画怎么走 | DFS/BFS、Tarjan（SCC / 割点桥）、Hierholzer |
| **二分图** | 能否两色染色 / 最多能配成多少对 | 染色法、匈牙利、KM（带权） |
| **网络流** | 源到汇最多能推多少流量 / 最大流为什么等于最小割 | Dinic、最小费用最大流 |
| **逻辑约束** | 二值变量 + 两两「或」约束，有没有解 | 2-SAT（蕴含图 + SCC） |
| **数值约束** | 一组只约束「差」的不等式，有没有解 / 解是什么 | 差分约束（转最短路 / 最长路 + 判环） |
| **树上问题** | 树上两点在哪「分叉」/ 路径整体怎么改 / 点对怎么统计 | LCA（倍增 / 欧拉序+RMQ / Tarjan）、树上差分、点分治 |

⭐ **图的表示决定了算法的一半** —— 但「怎么存」是**结构问题**，展开在姊妹目录：
[图的表示与存储.md](../../数据结构/图/图的表示与存储.md)（邻接表 / 邻接矩阵 / 边列表的空间与能力对照；共用的 `type Graph` 声明仍只写在 [DFS与BFS遍历.md](图的遍历/DFS与BFS遍历.md) 末节）。
本节只留**算法侧的结论**：**稀疏图用邻接表、稠密图用邻接矩阵、要反复扫全部边（Bellman-Ford、Kruskal）用边列表**。

⚠️ 这条判据的**真实体量已在本项目实测**（稠密图上 Floyd 反超 V 次 Dijkstra）——数字与推因见
[图的表示与存储.md](../../数据结构/图/图的表示与存储.md) 第二节与 [Floyd.md](最短路/Floyd.md) 第五节：**「稠密用矩阵、稀疏用链表」不是空话**。

## 二、适用条件

**本节要点**：图论的「适用条件」是**算法的前提**：负权、有向/无向、连通性、是否 DAG —— 前提不满足，算法不是变慢，而是**给出错误答案**。

| 前提 | 影响谁 | 违反的后果 |
|---|---|---|
| **边权非负** | Dijkstra | ⚠️ **静默算错**（[Dijkstra.md](最短路/Dijkstra.md) 第三节实测：错的不是 `dist[1]` 而是它没能传播到 `dist[3]`） |
| **无负环** | Bellman-Ford / SPFA | 最短路**没有定义**（每绕一圈更短）→ 必须检测并报错 |
| **DAG（无环）** | 拓扑排序 | 有环则**不存在**拓扑序（Kahn 收不满 `V` 个点即是信号） |
| **无向 + 连通** | 最小生成树 | 有向图要用**最小树形图**（另一个问题）；不连通得到的是**生成森林** |
| **顶点编号从 0 还是 1** | 全部 | 数组越界或漏一个点 —— 最常见的低级错误 |

### 典型应用场景

| 场景 | 归到哪个母题 |
|---|---|
| **网络路由** | 最短路（OSPF 用 Dijkstra、RIP 用距离向量 = Bellman-Ford 思想） |
| **地图导航** | 最短路（+ A* 启发式加速） |
| **任务调度 / 依赖管理** | **拓扑排序**（构建依赖、编译顺序、课程表） |
| **社交网络关系分析** | 最短路（最少跳数）/ 连通分量 |
| **网络铺设、电路布线、聚类** | **最小生成树**（MST 里删掉最长的边就是聚类） |

## 三、解题模板

**本节要点**：四步 —— **表示 → 遍历 → 选算法 → 处理边界**。第三步是全部判断力所在：**先看清图的前提，再选算法**。

| 步骤 | 做什么 | 关键点 |
|---|---|---|
| **1. 图的表示** | 邻接表（稀疏）/ 邻接矩阵（稠密）/ 边列表（要扫全部边时） | 选错会在「内存」或「速度」上付出代价（对照表见 [图的表示与存储.md](../../数据结构/图/图的表示与存储.md)） |
| **2. 图的遍历** | DFS（栈 / 递归）、BFS（队列） | 图有环 → **必须 `visited`**（[DFS深度优先遍历.md](图的遍历/DFS深度优先遍历.md)、[BFS广度优先遍历.md](图的遍历/BFS广度优先遍历.md)） |
| **3. 选算法** | 按母题与前提查下表 | ⚠️ **先看负权、再看连通性**，最后才看效率 |
| **4. 处理边界** | 重边、自环、负权、不连通、编号起点 | 这些在真实数据里都会出现（第六节列全了） |

### ⭐ 第 3 步：按母题查算法

```text
最短路（单源）
   ├─ 边权全非负？       → Dijkstra（堆优化 O((V+E)logV)）        [最短路/Dijkstra.md]
   └─ 有负权？           → Bellman-Ford（O(VE)，能检测负环）       [最短路/Bellman-Ford.md]
                             └─ 想更快且能接受最坏退化 → SPFA（队列优化版）

最短路（全源）
   └─ 图不大（V ≤ 数百）→ Floyd（O(V³)，代码只有三行）            [最短路/Floyd.md]

最小生成树（无向连通）
   ├─ 稀疏图             → Kruskal（按边排序 + 并查集）            [最小生成树/Kruskal.md]
   └─ 稠密图             → Prim（优先队列，O(V²) 或 O(E logV)）     [最小生成树/Prim.md]

拓扑排序（DAG）
   └─ 要顺序 / 判环 → Kahn（BFS，收不满即环）                      [拓扑排序.md]
      需要更强信息（SCC、关键路径）→ DFS 后序反转
```

### ⭐ 第 4 步：边界检查清单

```text
□ 有向还是无向？（影响建图：无向图每条边要加两次）
□ 有负权吗？      （影响 Dijkstra 能不能用）
□ 有负环吗？      （最短路必须先判——否则答案无意义）
□ 图连通吗？      （不连通时：最短路保留 ∞、MST 变成森林、拓扑排序收不满）
□ 有重边、自环吗？（建图时去重、或保留最小权的那条）
□ 顶点编号 0 起还是 1 起？
```

## 五、正确性证明

**本节要点**：图算法的正确性证明**主要靠两条工具** —— **贪心安全性**（Dijkstra、Prim、Kruskal）与**DP 的阶段不变式**（Bellman-Ford、Floyd）。

| 算法 | 走哪条路 | 核心不变量 |
|---|---|---|
| **[Dijkstra.md](最短路/Dijkstra.md)** | 贪心 + 松弛 | **非负权**保证「出堆的点距离已是最终值」（归纳证明） |
| **[Bellman-Ford.md](最短路/Bellman-Ford.md)** | DP / 逐轮松弛 | 第 `k` 轮之后，`dist[v]` ≤ 「最多用 `k` 条边」的最短距离 → `V−1` 轮必收敛 |
| **[Floyd.md](最短路/Floyd.md)** | 纯 DP | `k` 是**阶段**：只允许经过前 `k` 个点中转 ⇒ `k` 必须在**最外层**（放内层会静默算错） |
| **[Kruskal.md](最小生成树/Kruskal.md)** | 贪心（**割性质** / 环性质） | 每轮取全局最小且不成环的边，都是「安全边」 |
| **[Prim.md](最小生成树/Prim.md)** | 贪心（**割性质**） | 每轮取「跨当前割的最小边」，同样安全 |
| **[拓扑排序.md](拓扑排序.md)** | 不变量维护 | Kahn：每轮取入度为 0 的点 ⇒ 它前面必然都排好了 |

### ⭐ 两条通用工具

**① 贪心安全性**（Dijkstra / Prim / Kruskal 共用）：

```text
割性质：对任意把顶点分成两部分的「割」，横跨它的最小权边一定属于某棵最小生成树。
```

Dijkstra 的「出堆即定稿」和 Prim 的「拉进离树最近的点」都是这条性质的不同用法 ——
**共同前提是「边权非负」**（Dijkstra）或「无向」（Prim/Kruskal）。

**② 阶段不变式**（Bellman-Ford / Floyd 共用）：

```text
Bellman-Ford：第 k 轮结束 ⇒ dist[] 已经 ≤ 「最多 k 条边」的真值
Floyd       ：第 k 轮结束 ⇒ 允许用 {0..k} 中转时的最优值
```

⚠️ **Floyd 的「阶段必须在最外层」是这条不变式的直接推论** —— 放内层就破坏了「用上一阶段的值」这个前提（[Floyd.md](最短路/Floyd.md) 第二节有实测：`d[0][1]` 从 3 变成 `∞`）。

## 六、常见陷阱

**本节要点**：图论的坑**大半在「前提」上** —— 负权、连通性、编号，这些检查漏一个，算法就会给出错误结果（而不是报错）。

| 陷阱 | 症状 | 怎么避免 |
|---|---|---|
| **负权边导致 Dijkstra 失效** | 答案偏大，且**错得不明显** | 建图后先扫一遍边权；有负权就换 Bellman-Ford / Floyd |
| **有向图与无向图混淆** | 单向的边被当成双向 / 反之 | ⚠️ 无向图**每条边要加两次**；有向图只能加一次（[DFS深度优先遍历.md](图的遍历/DFS深度优先遍历.md) 讲过这个坑） |
| **重边、自环未处理** | 权重取错（应取最小重边）、自环造成死循环 | 建图时去重取最小；自环在多数问题里直接忽略 |
| **图不连通** | 最短路保留 `∞`、MST 变成森林、拓扑排序收不满 | **显式检查**「是否所有点都可达」，不要默认连通 |
| **节点编号 0 起还是 1 起** | 越界 / 漏一个点 | 建图时统一转换，别在不同函数里混着用 |
| **稀疏图用邻接矩阵** | 内存超限（`V = 10⁵` 时 10¹⁰ 个格子） | 按第一节末尾的结论选表示（对照表见 [图的表示与存储.md](../../数据结构/图/图的表示与存储.md)） |
| **只算距离、还原不出路径** | 拿到数值但拿不到路线 | 额外维护 `prev` / `next` 矩阵（[Floyd.md](最短路/Floyd.md) 第四节） |
| **Floyd 忘了判可达性** | 出现 `INF + 负权` 的**假值** | 内层加 `d[i][k] < INF && d[k][j] < INF` 判断（[Floyd.md](最短路/Floyd.md) 第三节） |
| **把 Tarjan 离线 LCA 当在线用** | 询问只能一次性给齐；逐条问就白写了 | 离线算法必须**成批**输入；要在线就用倍增或欧拉序 + RMQ（[树上问题.md](树上问题.md) 第四节） |
| **点分治漏掉「减去同子树」** | 点对被**重复计数**，结果偏大却不报错 | 容斥那一步不能省：每棵子树内的点对要在本层减掉（[树上问题.md](树上问题.md) 第六节） |

### 补一个「最坏情况」的坑

**Bellman-Ford / SPFA 的性能极不稳定**：

- Bellman-Ford 的轮数**取决于边的存储顺序** —— 本项目实测：同一张图，边表逆序要跑满 4 轮，正序**1 轮就收敛**；最坏情况（反向长链）比 Dijkstra 慢 **40~140 倍**；
- SPFA 平均很快（实测比 Bellman-Ford 省 77% 的边扫描），但**最坏仍是 `O(VE)`**，在对抗性数据上会被卡死。

⚠️ 所以：**能确定非负权就用 Dijkstra**，别用 SPFA 赌数据友好（[Bellman-Ford.md](最短路/Bellman-Ford.md) 第五节有实测数据）。

## 七、与其他思想对比

**本节要点**：图论是「**贪心与 DP 的主战场**」—— 表里这些算法，本质上都是贪心或 DP 在特定图结构上的实例。

### 图论 vs 贪心

| 算法 | 是不是贪心 | 贪心的是什么 |
|---|---|---|
| **Dijkstra** | ✅ | 每轮取「当前距离最小」的点 |
| **Prim** | ✅ | 每轮取「离已建成的树最近」的点 |
| **Kruskal** | ✅ | 每轮取「全局最小且不成环」的边 |
| Bellman-Ford / Floyd | ❌ | DP（逐轮 / 逐阶段） |

⭐ 这条对照的价值在于：**图上的贪心失效场景，与一般贪心完全同构** —— 一旦前提被破坏（Dijkstra 遇到负权），贪心就给出次优答案，而且**不报错**。

### 图论 vs 动态规划

| 关系 | 说明 |
|---|---|
| **Floyd 是纯 DP** | `dp[k][i][j]` 压成二维，`k` 是阶段（[Floyd.md](最短路/Floyd.md)） |
| **Bellman-Ford 是 DP 的「逐轮松弛」** | 轮数就是阶段数（[Bellman-Ford.md](最短路/Bellman-Ford.md)） |
| **DAG 上的最短路 = 按拓扑序做一次 DP** | 有向无环图不需要 Dijkstra，拓扑序天然给出 DP 的推进顺序（[DFS深度优先遍历.md](图的遍历/DFS深度优先遍历.md)） |
| **图上也有 DP 类问题** | 如「经过 k 条边的最短路」「状压 DP 跑 TSP」（[README.md](../动态规划/README.md) 的状态机 / 状压两类） |

### 图论 vs 回溯

| | DFS 遍历图 | 回溯 |
|---|---|---|
| 目标 | 访问所有节点（每个一次） | 枚举**所有路径 / 所有解** |
| 状态 | `visited` 即可 | 需要完整的**现场恢复**（撤销选择） |
| 复杂度 | `O(V + E)` | 指数级 |

⭐ 关系：回溯**就是** DFS 加「撤销」—— 走图时如果目标是「枚举所有路径」（而不是访问所有点），就必须用回溯的写法（[README.md](../回溯/README.md)）。区别只在**「同一个点能不能重复走」**：不能 → `visited` 就够了；能 → 必须撤销，否则会漏路径。
