# 高级技巧

> 本目录（`算法/高级技巧/`）收**区间 / 值域 / 递推 / 二维问题上的五把「换个角度」的刀**：
> [离散化.md](离散化.md)（大值域压成小值域，线段树等结构的前置步骤）、
> [分块.md](分块.md)（在线区间维护的第三把刀，单次 `O(√n)`）、
> [莫队算法.md](莫队算法.md)（离线区间查询：排序后只移动指针）、
> [扫描线.md](扫描线.md)（二维问题降成一维事件流）、
> [矩阵快速幂.md](矩阵快速幂.md)（线性递推第 n 项加速到 `O(log n)`）。
>
> 本篇是**入口总纲** —— 回答「这五样各自把什么难问题转成什么好问题、什么时候该进本目录、彼此谁依赖谁」。
> ⚠️ **模板与实现在各自的零件篇里**，本篇只给判据与阅读顺序；
> 算法目录整体导读见 [README.md](../README.md)，复杂度口径见 [复杂度分析.md](../基础算法/复杂度分析.md)。

## 一、核心思想

**本节要点**：五篇的共同点是「**换个角度看同一个区间 / 序列**」—— 先看清每篇把什么转成了什么。

| 篇 | 把什么转成什么 | 换来什么 | 代价 / 前提 |
|---|---|---|---|
| [离散化.md](离散化.md) | 大值域、稀疏取值 → 小值域、密集取值 | 数组开得起：线段树 / 树状数组才用得上 | 排序 + 去重 `O(n log n)`；原值 ↔ 下标两头都要映射得回去 |
| [分块.md](分块.md) | 整段区间 → 「整块用聚合、零头暴力」 | **不要求结合律**也能维护区间信息，且**在线**可用 | 单次 `O(√n)`；块大小与 lazy 记账要按操作配平 |
| [莫队算法.md](莫队算法.md) | 乱序的区间查询 → 按块排序后邻接的查询序列 | 每次只移动指针，`add` / `del` 摊到 `O(√n)` | **离线**才行；增删都必须能算（不可逆操作不行） |
| [扫描线.md](扫描线.md) | 二维矩形 / 覆盖问题 → 一维区间上的事件流 | 复用一维结构（线段树 / 排序）解二维题 | 事件排序 `O(n log n)`；y 轴「段与点」的下标坑 |
| [矩阵快速幂.md](矩阵快速幂.md) | 线性递推 → 矩阵乘法的幂 | 第 n 项从 `O(n)` 到 `O(k³ log n)` | 转移必须**线性**；取模与初始向量的对齐 |

⭐ 五篇里有两对是**同一问题的两条路线**：分块 ↔ 莫队（在线 vs 离线，对比表见 [分块.md](分块.md) 第六节、[莫队算法.md](莫队算法.md) 第六节），离散化 ↔ 扫描线（扫描线的 y 轴压缩就是一次离散化）。

## 二、阅读顺序与依赖关系

**本节要点**：先读离散化（最常用、其余四篇都会碰它），再按「区间问题」和「递推问题」分两条线走。

```text
   ../数学基础/数论基础.md ──快速幂──→ 矩阵快速幂.md ──加速线性递推──→ ../动态规划/线性DP.md

   离散化.md ──前置──┬──→ 扫描线.md（y 轴压缩）──需要──→ 区间与索引树.md（数据结构，线段树）
                     ├──→ 莫队算法.md（值域大时先压）
                     └──→ 分块.md（块内有序数组按下标操作时）

   分块.md ──「分块 + 排序」的思想──→ 莫队算法.md
   三篇区间问题（分块 / 莫队 / 上面的线段树）互为对照组
```

建议顺序：

| 步 | 读什么 | 为什么在这个位置 |
|---|---|---|
| 1 | [离散化.md](离散化.md) | 最短、被复用最多：扫描线、莫队、分块的值域维护都会用到 |
| 2 | [分块.md](分块.md) | 建立「整块聚合 + 零头暴力」的直觉，`√n` 是本目录的公分母 |
| 3 | [莫队算法.md](莫队算法.md) | 就是「把分块思想用在查询排序上」，紧接第 2 步读最顺 |
| 4 | [扫描线.md](扫描线.md) | 需要线段树打底（见 [区间与索引树.md](../../数据结构/树/区间与索引树.md)），配合离散化读 |
| 5 | [矩阵快速幂.md](矩阵快速幂.md) | 独立支线：快速幂已在 [数论基础.md](../数学基础/数论基础.md) 讲过，这里只是把它作用到矩阵上 |

## 三、什么时候进本目录（选型判据）

**本节要点**：一句话 —— **线段树那把刀不够用时**（不满足结合律 / 值域太大 / n 大到只能 `log n` 求第 n 项 / 问题是二维的），才进本目录找对应那篇。

```text
问题是什么形状？
├─ 区间查询 + 区间修改，维护量满足结合律（和 / 最值 / gcd）
│   └─ 线段树、树状数组 → 不在本目录，见 ../../数据结构/树/区间与索引树.md
├─ 同上，但维护量不满足结合律（区间众数 / 不同元素个数 / mex）
│   ├─ 查询能攒起来一次算（离线）→ 莫队算法.md
│   └─ 必须来一条答一条（在线）  → 分块.md
├─ 下标 / 值域很大但用到的点很少（1e9 的值、平面上稀疏的点）
│   └─ 先 离散化.md，再套上面的任意结构
├─ 二维图形（矩形面积并 / 区间覆盖计数 / 最近点对）
│   └─ 扫描线.md（y 轴配合 离散化.md）
└─ 线性递推求第 n 项（n 到 1e18，转移只有「加」和「常数倍」）
    └─ 矩阵快速幂.md
```

### ⭐ 三个自检

```text
□ 维护量满足结合律吗？（满足 → 线段树更简单，别上分块 / 莫队）
□ 题目允许离线吗？（允许 → 莫队；不允许 → 分块）
□ 转移是线性的吗？（出现非线性混合 → 矩阵快速幂建模不出来，回 DP）
```

## 五、常见陷阱

**本节要点**：五篇的坑集中在三处 —— **下标对齐、记账一致、适用前提**。

| 陷阱 | 后果 | 出处 |
|---|---|---|
| 离散化只排序不去重 / 丢原下标 | 映射回不去，或把相同值当成两个点 | [离散化.md](离散化.md) 第五节 |
| 扫描线把 y 轴「点」当「段」用 | 面积差一整行（下标 +1 坑的根源） | [扫描线.md](扫描线.md) 第五节 |
| 分块的 lazy 与块内 sum 双记账漏一处 | 整块查对、零头错（或反过来） | [分块.md](分块.md) 第七节 |
| 莫队只写 `add` 不写 `del`（增删不对称） | 区间收缩时答案不回收，结果偏大 | [莫队算法.md](莫队算法.md) 第八节 |
| 矩阵快速幂的单位矩阵 / 初始向量与幂次没对齐 | off-by-one，从第一项起全错 | [矩阵快速幂.md](矩阵快速幂.md) 第六节 |
| 拿莫队做在线题 / 拿分块硬顶线段树的活 | 前提不成立：写得再对也过不了，或白白慢一个 `√n` | 三篇的第一节「什么时候用」 |
