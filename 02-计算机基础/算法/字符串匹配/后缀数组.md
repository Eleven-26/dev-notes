# 后缀数组

> 把字符串的所有后缀按字典序排序，得到「后缀数组 SA」与「排名数组 Rank」——
> 是处理重复子串、最长公共前缀、多模式匹配的强力工具。
>
> ⭐ 边界先说清：本篇讲后缀数组的构造、性质与典型应用。
> 后缀自动机是另一条等价路线（见 [后缀自动机.md](后缀自动机.md)），本篇不展开。
> 基础匹配见 [KMP.md](KMP.md)、[字符串哈希.md](字符串哈希.md)。
>
> 内容整理自个人学习笔记，素材见 [素材清单](../../../素材清单.md)。复杂度口径见 [复杂度分析.md](../基础算法/复杂度分析.md)。

## 一、定义

**本节要点**：SA 是「排名 → 起始下标」，Rank 是「起始下标 → 排名」，两者互逆；排序对象是后缀，所以一张表就编码了**所有子串**的字典序信息。

对字符串 `s`，所有后缀按字典序排序后：

- **SA[i]**：排名第 i 的后缀的起始下标
- **Rank[i]**：后缀 `s[i..]` 的排名
- 关系：`Rank[SA[i]] = i`，`SA[Rank[i]] = i`（互为逆数组）

**例**：`s = "banana"`（下表排名从 1 开始编号，SA 数组按下标从 0 写）

| 后缀 | 排名 |
|---|---|
| a | 1 |
| ana | 2 |
| anana | 3 |
| banana | 4 |
| na | 5 |
| nana | 6 |

SA = [5, 3, 1, 0, 4, 2]

⭐ 读法：`SA[0] = 5` → 排名第 0（最小）的后缀从下标 5 开始，即 `"a"`；`Rank[4] = 5` → `"na"` 排第 5。两个数组就是同一张排序结果的正反两面。

## 二、构造方法

**本节要点**：倍增法的诀窍是「长度为 2k 的排名 = 两个长度为 k 的排名拼成的二元组排序」，把后缀比较降成整数对比较，log n 轮收敛。

| 方法 | 时间 | 说明 |
|---|---|---|
| 暴力排序 | O(n² log n) | 直接比较后缀 |
| 倍增法（DA） | O(n log n) | 最常用 |
| DC3 / SA-IS | O(n) | 复杂度最优，实现复杂 |

⭐ **倍增法思路**：先按长度 1 排序，再按长度 2、4、8… 排序，每次利用上一次的 Rank 快速比较。

以 `banana` 手推（`rank` 为该起点向后 `k` 长的排名，越界记 0）：

```text
k=1（单字符）：a=1 b=2 n=3 → rank = [2 1 3 1 3 1]

k=2：二元组 (rank[i], rank[i+1])
  i=0 (2,1)  i=1 (1,3)  i=2 (3,1)  i=3 (1,3)  i=4 (3,1)  i=5 (1,0)
  排序 → i5 < {i1,i3} < i0 < {i2,i4}
  新 rank = [3 2 4 2 4 1]        （同二元组并列同名次）

k=4：二元组 (rank[i], rank[i+2])
  i=0 (3,4)  i=1 (2,2)  i=2 (4,4)  i=3 (2,1)  i=4 (4,0)  i=5 (1,0)
  排序 → i5 < i3 < i1 < i0 < i4 < i2
  新 rank = [4 3 6 2 5 1]        （全部不同，已无并列）

k=8：二元组 (rank[i], rank[i+4])
  i=0 (4,5)  i=1 (3,1)  i=2 (6,0)  i=3 (2,0)  i=4 (5,0)  i=5 (1,0)
  名次与 k=4 完全一致 → 收敛

按 rank 反排：SA = [5, 3, 1, 0, 4, 2] ✓（与第一节的表一致）
```

⭐ 每轮排序的是**整数二元组**，可用基数排序做到每轮 O(n)，共 log n 轮 → 总 O(n log n)。

## 三、Height 数组与 LCP

**本节要点**：Height 只存「排名相邻后缀」的 LCP，就能推出任意两后缀的 LCP（区间最小值）；`Height[Rank[i]] ≥ Height[Rank[i-1]] − 1` 让它可以 O(n) 递推。

- **Height[i]** = `LCP(SA[i-1], SA[i])`，即排名相邻的两个后缀的最长公共前缀
- 利用性质：`Height[Rank[i]] >= Height[Rank[i-1]] - 1`，可 O(n) 求出
- 任意两个后缀的 LCP：转化为 Height 数组上的 RMQ（区间最小值）问题

仍用 `banana`，按 `i = 0..5` 顺序求（`SA = [5,3,1,0,4,2]`，`Rank = [3,2,5,1,4,0]`）：

```text
Height[0] = 0（约定）
i=1: LCP("a", "ana")      = 1
i=2: LCP("ana","anana")   = 3
i=3: LCP("anana","banana")= 0
i=4: LCP("banana","na")   = 0
i=5: LCP("na","nana")     = 2
→ Height = [0, 1, 3, 0, 0, 2]

验证性质：i=2 时 Rank[2]=5，Height[5]=2 ≥ Height[Rank[1]]−1 = Height[2]−1 = 2 ✓
最大值 3 → 最长重复子串 = "ana"（出现在下标 1 和 3）✓
```

⭐ LCP 是后缀数组最常用的能力之一：**最长重复子串、最长公共子串**都靠它。

## 四、典型应用

**本节要点**：后缀数组的价值在「排好序的重复信息」—— 相邻后缀的 LCP 直接给出重复子串；判模式串存在性则退化为在 SA 上二分。

| 场景 | 做法 |
|---|---|
| 最长重复子串 | Height 数组的最大值 |
| 最长公共子串（两串） | 拼接后求 Height，注意分属不同串 |
| 不同子串个数 | `n(n+1)/2 - sum(Height)` |
| 多模式匹配 | 二分 + LCP |
| 后缀排序 | 本身 |

用第三节的数据验一笔账：`banana` 不同子串个数 = `6·7/2 − (0+1+3+0+0+2)` = `21 − 6` = **15**。

⭐ 「多模式匹配二分」适合**文本固定、模式串随时来问**的场景；若模式集合固定、文本流式到来，正解是 [AC自动机.md](AC自动机.md)（一趟扫描命中全部），两者的选型判据见 [README.md](README.md) 第二节。

## 五、与后缀自动机的对比

**本节要点**：同一批信息（子串集合）的两种载体 —— 后缀数组是「排序后的数组 + LCP」，[后缀自动机.md](后缀自动机.md) 是「压缩所有子串的 DAG」；前者好写好调试，后者支持在线构造。

| 维度 | 后缀数组 | 后缀自动机 |
|---|---|---|
| 时间 | O(n log n) 或 O(n) | O(n) |
| 空间 | O(n) | O(n) |
| 实现难度 | 中 | 高 |
| 重复子串 | 靠 Height | 靠状态计数 |
| 常用度 | ⭐ 更高 | 较少 |

## 延伸追问

- **SA 和 Rank 什么关系？** → 互为逆数组：`Rank[SA[i]] = i`。
- **倍增法为什么是 O(n log n)？** → log n 轮排序，每轮 O(n)（基数排序）。
- **Height 数组怎么 O(n) 求？** → 利用 `Height[Rank[i]] >= Height[Rank[i-1]] - 1` 的单调性：按原串下标顺序算，每轮 LCP 至多比上一轮少 1，多出来的部分靠逐字符扩，总扩的量被 n 摊平。
- **后缀数组能替代 KMP 吗？** → 单模式匹配用 [KMP.md](KMP.md) 更简单（不用排序整个文本）；后缀数组适合多模式、重复子串类问题。
- **SA-IS 是什么？** → 线性时间构造后缀数组的算法，实现复杂但复杂度最优。
