> 覆盖安装与磁盘分区、XFS 文件系统、用户与权限、Shell 脚本、systemd、nmcli、
> journalctl、软件包管理、备份恢复与系统管理综合；以 CentOS 7.x 为基准，

## 版本坐标速查

**本节要点**：书基于 CentOS 7.x，现代发行版与它的差异集中在下面这几个组件上，读的时候先对号。

| 特性 | 鸟哥第四版（CentOS 7.x） | 现代发行版（Rocky 9 / Ubuntu 22.04+） | 备注 |
|------|--------------------------|--------------------------------------|------|
| systemd | ✅ | ✅ | CentOS 7 是 systemd 219，现代是 250+ |
| XFS | ✅ 默认 | ✅ 默认 | XFS 不支持缩容 |
| GPT | ✅ | ✅ | parted / gdisk |
| nmcli | ✅ | ✅ | NetworkManager |
| journalctl | ✅ | ✅ | systemd-journald |
| cgroups | ✅ v1 | ⚠️ v2 | 容器场景要区分 |
| firewalld | ✅ | ✅ | 现代更多用 nftables 后端 |
| yum | ✅ | ⚠️ dnf | CentOS 8+ / Rocky 用 dnf |
| 服务器架设 | ✅ | 部分被容器 / K8s 替代 | 原理仍有效，见 [README.md](../鸟哥服务器架设篇/README.md) |

## 延伸追问

- **CentOS 7 都 EOL 了，还按它学值得吗？**
  → 值得。进程、权限、systemd、fstab、inode 这些**抽象**在现代发行版里没变；变的是包管理器（yum → dnf）、cgroup 版本（v1 → v2）与防火墙后端（iptables → nftables）。读的时候把「抽象」和「命令」分开，差异各篇都已标注。
- **先读本目录还是先读原理篇？**
  → 想「会用」先读本目录，想「说清为什么」回头读原理篇；两者在每篇的「关联」里互相指路。
- **服务器架设为什么不并进来？**
  → WWW / DNS / DHCP / 文件共享 / 邮件这一块体量够大，单独成 [README.md](../鸟哥服务器架设篇/README.md) 目录；本目录的 ⑥ 只讲「主机自己怎么联网」。
