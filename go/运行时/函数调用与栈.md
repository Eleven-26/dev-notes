## Q1. 调用一个函数的具体过程是怎样的？

**来源**：`p=67` 腾讯 Go 后台开发面试 · 时长 2分53秒
**考察意图**：⚠️ **这是一道"态度题"而不是"能力题"**——原视频讲得很直白，值得单独记下这个判断。

### 一、先看这类题的性质

> **重点是「面试官问了、你答上来了」，而不是答案有多精准。**
>
> 因为**函数的调用过程是一成不变的、几乎不会变化**——
> 它是这么调就这么调，整个流程固定。
>
> **它不具备扩展性**，我们也**不会基于"函数调用过程"去优化代码**。

### 二、所以怎么应对

| 做法 | 说明 |
|---|---|
| **直接背下来** | 通过搜索引擎或 AIGC 查询"函数调用过程"，<br>拿到的答案基本**大差不差**，背下来即可 |
| **不必纠结精度** | 不需要去看源码，也不需要考证每个细节是否绝对准确 |
| **要能接住** | 面试时**答上边**就行 |

### 三、这题到底在考什么（理解了就不慌）

> **它考的是：你有没有开始关注底层逻辑，
> 而不是停留在"我会用"的应用层。**
>
> 很多面试官问这个问题时，**自己未必能完整答上来**——
> 他要的是一个信号：**你愿意往下看一层**。

### 面试建议

> **面这类"死知识"题，不要试图现场推导**——
> 直接把标准流程背熟、流利地讲出来，**比支支吾吾地"思考"效果好得多**。

## Q2. 栈里面除了局部变量、函数参数、返回值，还有什么？

**来源**：`p=68` 腾讯 Go 后台开发面试 · 时长 2分58秒
**考察意图**：这类题的共同点是——**考你有没有了解底层**，答案**能答出几个就行**。

### 六个部分（大概记住这六类即可）

| # | 内容 |
|---|---|
| **①** | **函数调用的相关信息**（如返回地址、栈帧指针等） |
| **②** | **函数参数、返回值、局部变量** |
| **③** | **寄存器状态**（需要保存/恢复的寄存器值） |
| **④** | **协程的相关信息** |
| **⑤** | **异常处理的相关信息**（`panic` / `recover` 相关） |
| **⑥** | **Go 特有的 `defer` 延迟调用信息** |

> **答题标准（原视频的建议）**：
> **能答出几个就够，不必答得多么精准漂亮**——
> 因为面试官自己也**未必能精确描述**栈里到底有什么。

### 面试官会追问什么

- **Go 的栈和线程栈有什么区别？** → **goroutine 栈是可增长的**：
  初始仅 **2KB**，不够时**自动扩缩容**（这也是 goroutine 比线程轻的关键）。
- **栈扩容时旧栈上的指针怎么办？** → 运行时**会扫描并调整所有指向旧栈的指针**
  （这也是 Go 需要精确 GC 类型信息的原因）。
- **逃逸和栈的关系？** → **逃逸就是"本该在栈上的变量被放到了堆上"**（见 [内存逃逸.md](内存逃逸.md)）。
