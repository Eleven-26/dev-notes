> 因果集群与高可用、GDS 图算法、数据建模与导入、运维调优、向量索引与

> Manual、Operations Manual；**5.x / 2026.x 新特性**（向量索引、Cypher SEARCH、

## 二、版本坐标速查

⭐ **一条线看清「哪一版能做什么」**——本仓各篇会反复引用这张表里的版本事实（版本号 / 日期以官方 Release Notes 为准）：

| 特性 | 引入版本 | 说明 |
|---|---|---|
| 无索引邻接（Index-Free Adjacency） | 1.x | 原生图存储的核心机制，Neo4j 的立身之本 |
| Cypher 查询语言 | 1.x | 声明式图查询，后来是 GQL 标准的主要参考 |
| 因果集群（Causal Clustering） | 3.1+ | Core / Read Replica + Raft，同时替代 3.5 起弃用的 HA 集群 |
| 全文索引（基于 Lucene） | 3.5 | 支持 `CONTAINS` / `ENDS WITH` 式的分词检索 |
| GDS 图算法库 | 4.x | 独立于数据库运行的图算法引擎 |
| 原生向量索引 | 5.11 | 多维向量相似性搜索（HNSW） |
| Java 17 为最低要求 | 5.x | 5.x 全线跑在 Java 17 上 |
| Cypher SEARCH 子句 | 2026.01+ | 向量搜索的原生 Cypher 语法，取代过程调用 |
| 带过滤的向量搜索 | 2026.02 | GA，在索引内部按属性过滤 |
| Java 25 支持 | 2025.10 | 跟进最新 LTS |
| GQL 对齐 | 5.x | Cypher 已覆盖 GQL 大部分强制特性 |
| 发现服务（Discovery Service）v1 移除 | 2025.01 | 集群发现机制更新 |
| Aura Graph Analytics | 2026 | 基于 GDS 的按需（serverless）图计算环境 |
| Neo4j Studio | 2026 | Browser + Bloom + NeoDash 三合一 |

⭐ 两条使用纪律：

- **5.26 是本仓实测所落版本**（5.x 的 LTS 线）。上表 5.11 及以前的能力**全部实测**；
  2025.x / 2026.x 的四项（Cypher SEARCH、带过滤向量搜索、Aura Graph Analytics、Neo4j Studio）
  **在 5.26 上跑不了，各篇标"未实测"并给出官方文档出处**。
- ⚠️ **5.x 起配置文件批量改名**：`dbms.memory.*` → `server.memory.*`、`dbms.logs.query.*` → `db.logs.query.*`，
  且 `db.logs.query.enabled` 不是布尔值而是枚举 `OFF|INFO|VERBOSE`（写 `true` 直接启动失败，实测踩过，
  见 [运维与调优.md](运维与调优.md) 第二节）。老教程里的 `dbms.*` 写法照抄会起不来。
