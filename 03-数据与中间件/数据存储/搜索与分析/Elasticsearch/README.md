## 一、总览

Elasticsearch 是一个分布式、RESTful 的搜索和数据分析引擎。

### 1.1 优点

+ 高性能：倒排索引
+ 易扩展：分布式
+ 容错性好：副本机制
+ 上手快：RESTful API，社区活跃

### 1.2 使用场景

+ 在线实时日志分析，ELK(Elasticsearch、Logstash、Kibana)和 Elastic Stack
+ 物联网(internet of things，IoT)数据监控
+ 文献检索和文献计量
+ 商务智能(business intelligence，BI)大屏展示

### 1.3 选型：什么时候该用 ES

+ 写少读多
+ 不支持事务
+ 数据量大、响应要快
+ 使用 SQL 、NoSQL 也无法满足（避免过度设计）

### 1.4 搜索引擎的四个模块

通常搜索引擎包括数据采集模块、文本分析模块、索引存储模块、搜索模块等，这些模块的协作流程是：

+ 数据采集模块：负责采集数据；
+ 文本分析模块：负责将原始文本数据切分成有意义的分词以便于搜索；
+ 索引存储模块：负责将数据组建成倒排索引以实现高速搜索；
+ 搜索模块：负责根据用户的查询条件返回最相关的搜索结果。

## 二、版本坐标

⭐ **一条线看清「哪一版能做什么」**——本仓各篇会反复引用这张表里的版本事实（版本号 / 日期以官方 Release Notes 为准）：

| 版本线 | 时间 | 与检索 / 存储相关的关键事实 |
| --- | --- | --- |
| 5.0 | 2016-10 | BM25 取代 TF-IDF 成为默认相似度 |
| 7.0 | 2019-04 | 一个索引只允许一个 type；默认主分片数由 5 改为 1；7.17 是 7.x 终版（维护已于 2026-01 结束） |
| 8.0 | 2022-02 | `dense_vector` + ANN（HNSW）向量检索 GA；默认开启安全（TLS + 认证） |
| 8.11 / 8.12 | 2023-11 / 2024-01 | ES\|QL 技术预览；**标量量化**（scalar quantization）引入 |
| 8.15 / 8.16 | 2024-08 / 2024-11 | **int4（半字节）量化**；**BBQ（Better Binary Quantization）技术预览**；`best_compression` 底层改用 ZSTD |
| 8.17 | 2024-12 | **logsdb index mode GA**（日志存储最多降约 65%）；Elastic Rerank 技术预览；ES\|QL 的 `MATCH` / `QSTR` |
| 8.18 | 2025-04 | ⭐ **BBQ GA**（底层换成「优化的标量量化」，召回与吞吐同时提升）；`route_on_sort_fields` |
| 8.19 | 2025-07 | 8.x 最后一个次版本（支持到 2027-07），**本仓实测就落在这一版** |
| 9.0 | 2025-04 | 基于 **Lucene 10**；`semantic_text` GA；`rank_vectors` 字段；ES\|QL `LOOKUP JOIN` |
| 9.1 | 2025-07 | 彻底移除 recovery source：对等恢复写 IO 约降 50% |
| 9.2 / 9.3 | 2025-10 / 2026-02 | `pattern_text` 技术预览 → GA；`bfloat16` 向量；`exponential_histogram` |
| 9.4 / 9.5 | 2026-05 / 2026-08 | 当前维护线 |

> ⚠️ 两个最容易踩的版本差异：**8.x 起默认开启安全**（本地调试要显式关掉或配证书）；**BBQ 走 `index_options` 而不是 `index.codec`**（8.19 实测 `index.codec: bbq` 直接报 400，详见 [向量与AI搜索.md](向量与AI搜索.md)）。
