> 本目录是「分布式协调」这一子类的**产品级横评入口**：分布式锁、Leader 选举、变更监听三类需求，
> 在 Redis / etcd / ZooKeeper / 数据库唯一键四种底座上怎么取舍。
> **总纲是 [分布式协调选型对比.md](分布式协调选型对比.md)** —— 三类需求的要求、四种底座的对比、
> Redis 锁的争议，全都在那一篇里，本文件**只做指路，不重复内容**。
>
> ⭐ **上一层**（要不要引协调族、引哪一子类）见 [中间件选型.md](../中间件选型.md) 第四节；
> 本篇是它的族内横评（产品粒度）。
>
> 内容整理自个人学习笔记。素材见 [素材清单.md](../../../素材清单.md)。
